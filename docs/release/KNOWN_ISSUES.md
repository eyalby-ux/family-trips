# Known Issues — Alpha 0.2.1

1. No OCR or full document extraction.
2. Uploaded file bytes are not persisted; file sources remain metadata-only.
3. File sources cannot be reopened after the original local file-picker session.
4. External map selection is not embedded.
5. Only one active local Trip is supported.
6. Accounts, private/shared Trips, and concurrent editing are planned for Alpha 0.3.
7. Pasted text containing a URL is not parsed; only a clean URL opens correctly. Schedule: Alpha 0.4.
8. A linked source URL cannot yet be edited. Schedule: document/source ownership.
9. Multi-day items are displayed on their start date only in Calendar. Schedule: Alpha 0.5.
10. Category-level Add does not preselect the current category.
11. Trip Center density and FAB overlap require Beta refinement.
