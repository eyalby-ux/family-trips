# Known Issues — Alpha 0.2.1

1. No OCR or full document extraction.
2. Uploaded file bytes are not persisted; file sources remain metadata-only.
3. File sources cannot be reopened after the original local file-picker session.
4. External map selection is not embedded.
5. Only one active local Trip is supported.
6. Accounts, private/shared Trips, and concurrent editing are planned for Alpha 0.3.
