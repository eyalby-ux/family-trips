# Release Notes — Family Trips Alpha 0.1

Package date: 2026-07-26  
Status: Installable testing Alpha

## Included

- Empty initial state.
- Trip creation from the first accepted document or saved item.
- Today, Timeline, Trip Center, and one Detail View.
- Basic item CRUD.
- PDF and image metadata intake.
- Editable Trip dates.
- Conflict detection without silent date rewriting.
- Local persistence.
- PWA and basic offline shell.
- GitHub Actions and Netlify configuration.
- Full English technical documentation.
- Codex repository instructions.

## Objective

Validate onboarding, intake, navigation, Trip date editing, persistence, and conflict behavior before OCR and full Smart Ingestion.
